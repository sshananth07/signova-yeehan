# Pain-map anatomy models

- `body.glb`: muscular system (the tappable body)
- `inside.glb`: internal organs (the "Inside" layer)

Built by `scripts/prepare-anatomy.mjs` from https://github.com/DrMuratAltun/anatomi-simulatoru
(`systems/kas.glb`, `systems/ic-organlar.glb`): fascia, genital structures and labels removed,
geometry simplified, meshopt-compressed. Each node keeps its anatomy name in `extras.n`.
